# 常態範式

**常態範式**（normalcy paradigm）是以特定的“正常”身心模式評價神經認知差異，並將偏離常態默認視爲病理的框架。[[ChapmanFletcherWatson2026|Chapman 與 Fletcher-Watson（2026）]]用這一術語分析常態、健康及非典型性之間的關係：當符合常態被視爲健康和良好功能的標準時，差異便容易成爲需要糾正的對象。這個概念關注科學研究與日常文化中的基本假設，以及這些假設如何影響問題的提出、經驗的解釋和改善目標的選擇。相關討論與Nick Walker提出的**病理學範式**（pathology paradigm）密切聯繫，後者着重分析正常心智、內在缺陷和正常化目標之間的關係。

## 常態、健康與理想表現

理解常態範式，可以從幾種經常被聯繫起來的判斷入手：

| 判斷所關注的問題 | 含義 | 可以進一步追問的內容 |
|---|---|---|
| 某種表現是否常見 | 相對於某個人羣或參照範圍的典型程度 | 比較對象如何選擇，差異怎樣分佈 |
| 某種狀態是否影響健康與福祉 | 個體的身體、心理體驗和生活狀況 | 是否涉及痛苦、活動困難或支持需要 |
| 某種表現是否值得追求 | 對能力、行爲和生活方式的價值評價 | 誰設定目標，目標服務於何種需要 |

在Chapman與Fletcher-Watson的分析中，常態範式把這些判斷緊密捆綁：某種典型模式既成爲解釋差異的基準，也成爲評價人的能力和決定改變方向的尺度。由此，接近常態本身便可能被當作改善。

[[MullerKosmarovChapman2026|Müller-Kosmarov 與 Chapman（2026）]]還強調能力排序這一面向：人們按照既定的心智功能標準被排列爲較低、正常或較高的等級，更高排名被賦予更優越的價值。這個分析把注意引向統計描述如何轉化爲理想，以及評價尺度如何組織社會中的機會與地位。

## 病理學範式

Nick Walker 在[*Throw Away the Master’s Tools: Liberating Ourselves from the Pathology Paradigm*](https://neuroqueer.com/throw-away-the-masters-tools/)中，將“病理學範式”（pathology paradigm）概括爲一組基本假設：存在一種正確或健康的神經認知方式，明顯偏離這種方式的人則被視爲具有內在缺陷。（文章初版發表於2012年，作者網站提供的是2013年修訂版。）

### 正常心智與內在缺陷

Walker把這組前提進一步歸納爲兩項：

1. 人類大腦與心智存在一種正確、正常或健康的配置與運作方式，或者應當落在一個相對狹窄的正常範圍內。
2. 當一個人的認知、思考和行爲明顯偏離這個標準時，這種偏離被解釋爲此人自身出了問題。

在Walker的論述中，這兩項假設爲病因解釋、分類和干預提供了共同前提。不同倡導者可能在差異從何而來、應採取何種措施等問題上相互爭論，同時共享以正常心智爲理想、以偏離爲缺陷的出發點。病理學範式因此涉及一整套解釋方式，貫穿研究、服務、家庭期待與公共敘事。

### 缺陷歸因與正常化目標

這一框架把典型表現作爲衡量個體的尺度，將人與環境、人與人之間的困難主要定位在偏離標準的一方。Walker以溝通爲例：當[[神經典型]]者和孤獨譜系者彼此難以理解時，解釋容易集中於孤獨譜系者的溝通或同理心缺陷。這裏值得分析的是，同一次互動中各方的表達、理解和環境條件，如何被納入原因說明。

缺陷歸因也參與決定改善目標。如果差異本身被看作問題，減少差異、使表現接近典型，便成爲干預成功的直觀尺度。[[Dwyer2022|Dwyer（2022）]]以自我刺激行爲說明這種目標取向：把減少這類行爲設爲目標，與調整環境、減輕壓力並由此改變行爲，體現了不同的問題理解和評價依據。

這使病理學範式的分析能夠同時關注三個環節：以何種認知方式作參照，如何解釋偏離，以及爲什麼把某種改變視爲進步。研究和支持措施的具體內容，都可能受到這些前提的組織。

### 病理化語言與自我理解

Walker進一步討論語言如何固定這些判斷。“症狀”“受損”等詞把經驗放進病理敘事；當某一認知方式成爲默認標準時，“高功能”和“低功能”又可能把接近這一標準的程度寫成對整個人的總體評價。語言在這裏同時承擔描述、分類和價值排序的作用。

這種敘事也可能進入[[神經殊異]]者的自我理解。Walker用“內化壓迫”討論人們如何吸收有關自身缺陷的社會信息，並以這些信息評價自己的身份與可能性。[[Dwyer2022|Dwyer（2022）]]對缺陷觀念和預期的討論，則把這一問題聯繫到教育與支持關係：怎樣描述一個人，會影響周圍人對其學習、參與和發展機會的期待。

## 術語來源與相關概念

### 從病理學範式到常態範式

Chapman與Fletcher-Watson（2026）沿用這一批判方向，選擇了“常態範式”這一名稱來突出將常態等同於健康、將非典型性等同於病理的推理。他們把回應的重點放在[[去病理化|克服默認病理化]]，並依據具體經驗討論健康、殘障與支持。

### 與醫學模型和神經規範性的關係

這幾個概念在討論中相互聯繫，各自強調的層次如下：

| 概念             | 主要關注                                |
| -------------- | ----------------------------------- |
| 常態範式           | 解釋和評價神經認知差異時採用的基本假設，尤其是常態與健康的綁定     |
| 病理學範式          | Walker對相近問題的命名，突出把非典型認知方式理解爲內在缺陷的取向 |
| [[殘障模型\|醫學模型]] | 對殘障的解釋方式，主要將問題定位於個體身心的損傷或功能障礙       |
| [[神經規範性]]      | 特定認知和行爲方式如何成爲社會期待，並影響制度、互動與資源分配     |

用這些層次理解同一情境，可以分別考察評價依據、問題的歸屬，以及社會如何回應差異。例如，一項溝通支持的目標可能涉及表達需要、參與互動，也可能涉及表現是否接近慣常的社交方式；常態範式的分析關注這些目標如何被選擇和排序。

## 歷史分析

[[Chapman2023|Chapman（2023）]]在《正常帝國》中，將常態標準的發展放在資本主義生產、能力測量及社會分類相互作用的歷史中考察。這是一種關於常態與權力關係的歷史解釋：工作組織需要怎樣的勞動者，哪些能力受到獎勵，以及哪些人被排除，會影響人們怎樣理解正常與異常。

### 工業勞動與能力標準

Chapman討論工業生產中的工作日、勞動節奏和效率要求如何逐漸標準化，並由此形成對勞動者身體與心智的共同期待。在這一敘述中，生產能力參與塑造了社會對獨立、合格和有價值的人的理解；與既定要求不相適應的人，則更容易面臨分類、隔離及機會受限。

### 心理測量與等級秩序

Chapman將Francis Galton的能力排序、心理測量和優生學思想視爲病理學範式形成的重要環節，並討論這些思路如何經由Emil Kraepelin等人進入精神病學與心理科學。其論證關注的是：社會中的等級和理想，如何藉助測量與分類，被表述爲有關人類自然差異的知識。

在Chapman的解釋中，資本主義的制度邏輯與這一知識框架相互強化。更具體的統計史、分類史及優生學討論，見[[常態的發明]]、[[優生學]]和[[神經多樣性與資本主義]]。

## 科學研究與文化中的運作

Chapman與Fletcher-Watson（2026）將常態範式放在科學與文化兩個相互聯繫的層面討論。研究中的分類和解釋會影響公共理解，日常生活中的價值期待也會進入研究問題、測量工具及評價指標。

在研究中，這種關係體現在比較組的選擇、差異的命名以及干預結果的定義。例如，研究可以詢問某種支持是否讓行爲更接近典型表現，也可以詢問它是否改善溝通、減輕痛苦或增加參與機會。不同問題會使不同經驗和結果進入關注範圍。

在文化中，這種關係體現在人們如何敘述[[神經殊異]]者的生活：哪些行爲被理解爲得體或成熟，哪些經歷被寫成成功、失敗或悲劇，以及社會期待人們改變什麼。科學分類與文化敘事由此共同塑造對差異的認識。

[[Botha2025|Botha（2025）]]從科學哲學角度討論研究中的本體論、知識觀、方法與價值目標。她以孤獨譜系研究爲例，主張通過批判實在論和社羣參與，結合物質經驗、社會情境與當事人的知識。這個討論進一步說明，檢視範式也涉及誰能夠提出問題、哪些經驗進入證據，以及研究爲誰服務。

## 與神經多樣性範式的討論

[[神經多樣性範式]]推動的轉變，涉及如何解釋差異，也涉及用什麼尺度評價改變。Walker強調認知多樣性的價值；Chapman與Fletcher-Watson（2026）以“肯定複雜性”和“將神經規範性政治化”說明其方向，將不同認知經驗、支持需要和制度安排納入討論。

[[Dwyer2022|Dwyer（2022）]]提出的互動主義神經多樣性方法，把殘障放在個體特徵與環境的互動中理解。依照這一立場，支持可以涉及個體、環境或二者的改變，評價重點是福祉、生活質量及本人對目標的參與。

這種討論把研究和實踐帶向幾個具體問題：當事人希望改變什麼，哪些環境要求造成困難，支持是否增加自主與參與，以及結果如何由受影響的人共同評價。常態範式因而提供了一種審視既有尺度的方式，使原先被默認的目標成爲可以討論和重新選擇的對象。

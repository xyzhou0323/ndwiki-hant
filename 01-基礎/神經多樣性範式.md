# 神經多樣性範式

**神經多樣性範式**（neurodiversity paradigm）是理解、研究和回應神經認知差異的一組科學、倫理與政治立場。相關論述肯定[[神經多樣性]]的價值，考察差異與身體、環境和社會關係的聯繫，並將福祉、自主決定及社會參與作爲研究和支持的重要目標。它也關注誰有權解釋這些經驗、定義需要改變的問題，以及決定什麼算作改善。

## 範式、框架與方法羣

[[Walker2014|Walker（2014）]]將神經多樣性範式描述爲理解人類心智差異的特定視角，並將其與差異本身及圍繞權利開展的[[神經多樣性運動]]區分。這一視角涉及對人的價值、認知標準和社會權力關係的判斷，爲研究、教育和倡權等實踐提供思想資源。

“範式”也表達了改變科學與文化中基本假設的意圖。[[MullerKosmarovChapman2026|Müller-Kosmarov 與 Chapman（2026）]]藉助科學哲學中的範式概念，說明這些假設會影響問題如何提出、數據怎樣解釋，以及人們怎樣理解神經殊異者的社會位置。[[ChapmanFletcherWatson2026|Chapman 與 Fletcher-Watson（2026）]]同樣從科學與文化兩個層面討論這種轉變。

不同作者對理論的表述和具體主張有所不同。[[Dwyer2022|Dwyer（2022）]]採用“神經多樣性方法羣”（neurodiversity approaches），強調殘障解釋、干預和適用範圍等議題中的實質性分歧。Müller-Kosmarov與Chapman則討論了“範式”與“框架”等稱謂的不同含義：前者突出了轉變的深度與廣度，也帶來了如何理解科學變遷的哲學問題。

## 範式關注的問題

相關論述從理解差異延伸到研究、支持和公共生活。下表概括其中幾項相互聯繫的問題，具體主張在後文按作者展開：

| 問題 | 討論焦點 |
| --- | --- |
| 怎樣理解差異？ | 神經認知方式的多維性、具身經驗，以及個體與集體生活的聯繫 |
| 怎樣解釋殘障？ | 身體特徵、活動要求、環境條件與社會障礙如何共同影響生活 |
| 什麼需要改變？ | 哪些體驗、行爲或環境造成痛苦、限制行動或妨礙參與 |
| 支持追求什麼？ | 福祉、生活質量、自主決定及具體參與機會 |
| 誰參與判斷？ | 當事者、社羣、支持者及專業人員怎樣共同確定問題和目標 |
| 研究怎樣開展？ | 研究議程、概念、測量、結果解釋與社羣參與如何組織 |

## 差異的價值與複雜性

Walker（2014）將神經多樣性視爲自然且有價值的人類多樣性，並關注不同認知方式之間的社會權力關係。[[PellicanodenHouting2022|Pellicano 與 den Houting（2022）]]進一步將對多樣性的肯定與人的尊嚴聯繫起來：無論某種差異是否帶來集體益處，人都應因其自身而受到尊重。這使社會接納與資源支持具有獨立於生產能力或特定優勢的倫理依據。

Chapman與Fletcher-Watson（2026）以**肯定複雜性**（affirm complexity）概括其理論方向之一。他們強調同一診斷類別內部的異質性、人的生命歷程，以及不同個體在身體、認知、環境和支持需要上的差異。研究與實踐由此需要容納多種經驗，並具體理解哪些條件能使人們生活得更好。

Müller-Kosmarov與Chapman（2026）還從個體與集體兩個層面討論心智功能：不同認知方式可以在合作、知識和共同生活中發揮作用。這樣的分析將差異放入人與人之間的關係中考察，擴展了以個體能力排序理解功能的視野。

## 神經規範性與評價標準

Chapman與Fletcher-Watson（2026）的另一項主張是**將神經規範性政治化**（politicize neuronormativity）。[[神經規範性]]涉及哪些認知、情緒、感官或行爲表現被視爲理想，以及這些評價如何影響社會位置和機會。作者要求把這些標準放回其社會、文化與歷史條件中，考察它們如何產生、服務於哪些安排，以及由誰承擔適應的代價。

這也涉及[[常態範式]]所討論的正常、健康與理想功能之間的聯繫。對於學習、交流或工作的困難，需要具體說明評價依據：某種表現是否造成痛苦或活動限制，環境是否容納不同方式，所追求的改變與誰的目標相符。Müller-Kosmarov與Chapman（2026）將此概括爲範式的概念與規範兩個層面，即如何理解心智功能，以及據什麼理由評價差異和選擇回應。

## 殘障解釋與支持目標

### 個體與環境的互動

Dwyer（2022）提出一種互動主義的神經多樣性方法，將殘障理解爲個體特徵與環境共同作用的結果。這樣的解釋同時關注身體體驗、功能限制、環境要求和歧視等因素，支持也可以圍繞個人技能、環境調整或二者的結合展開。具體的模型區別見[[殘障模型]]。

在這一方案中，選擇支持方式的依據是它怎樣改善生活質量。個人與環境的作用需要一起分析，目標則結合具體情境中的困難、活動和當事者意願來確定。Dwyer以自我刺激行爲說明目標的差別：改善環境、減輕壓力後某種行爲隨之減少，與把壓制該行爲本身作爲目標，具有不同的倫理含義。

### 福祉、自主與生活質量

Dwyer反對以正常化或“治癒”殘障者爲目標的干預，同時討論了教授技能、使用藥物緩解困難及改變環境等支持。這是作者所提出的規範性方案，需要與其他作者的具體論述結合理解。

Chapman與Fletcher-Watson（2026）將醫療照護、社會支持和對不同存在方式的理解共同納入肯定複雜性的要求。他們以癲癇、癡呆等情況說明，人的神經殊異經驗可能包含實際疾病和照護需要；研究、服務和政策應回應不同情境中的需要。關於支持和干預的具體倫理討論見[[ASD干預]]，差異與殘障身份的聯繫見[[神經多樣性與殘障]]。

## 研究問題與知識生產

[[PellicanodenHouting2022|Pellicano 與 den Houting（2022）]]從孤獨譜系科學出發，討論了傳統研究中過度聚焦缺陷、側重個體而忽略環境，以及當事者聲音被排除等問題。他們主張擴大研究對象與解釋視野，讓孤獨譜系者參與研究議程及相關決定。這樣的改變同時涉及研究什麼、如何理解結果，以及知識由誰共同生產。

[[HeratyEtAl2023|Heraty 等（2023）]]將這些問題帶入生物醫學研究。他們主張與社羣共同確定有意義的研究問題和結果指標，在項目範圍設定及申請資助的早期開展參與，並共同解讀研究發現。他們還討論了研究敘事如何影響整個羣體，以及資助和學術制度怎樣支持持續合作。

在這些論述中，生活經驗是確定問題、理解測量和評價結果的重要知識資源。關於研究中的參與與決定權，見[[神經多樣性與民主研究]]；共同研究並推動行動的方法討論見[[參與式行動研究]]，更廣的學科與方法論討論見[[神經多樣性研究]]。

## 適用範圍與診斷分類

Dwyer（2022）將適用範圍視爲尚在討論的問題。不同人對某種特徵與自身身份、痛苦或生活目標的關係，可能有不同理解；這些差異會影響人們希望獲得什麼支持，以及神經多樣性方法與醫學方法如何結合。

診斷分類也同時承擔多種功能。Dwyer指出，同一類別內部具有異質性，類別之間可能共現；類別又能幫助人們組織經驗、形成社羣、開展研究和取得支持。範式中的分類討論因而涉及如何描述維度性差異，以及怎樣使分類回應實際經驗和社會需要。相關術語範圍見[[神經殊異]]。

## 科學哲學與進一步討論

[[Botha2025|Botha（2025）]]從社區心理學出發，提出批判實在論作爲理解孤獨譜系及開展社會正義研究的一種科學哲學資源。它承認現實中的結構和因果作用，同時將科學知識理解爲受社會條件、觀察方法和解釋影響、可以修正的認識。Botha據此討論如何結合物質處境、社會不平等和當事者參與，開展能夠改善生活的研究。

Müller-Kosmarov與Chapman（2026）則將神經多樣性哲學的討論延伸到知識、具身體驗、身份及政治倫理等方向。這些研究繼續追問：哪些經驗能成爲知識，診斷與自我理解怎樣聯繫，以及支持和公共生活應怎樣組織。相關專題見[[知識不正義]]、[[去病理化]]與[[神經多樣性與交叉性]]。理論的社羣背景和組織發展另見[[神經多樣性運動史]]。
